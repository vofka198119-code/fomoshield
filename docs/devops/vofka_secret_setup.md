# Инструкция для vofka — публичный репозиторий релизов + секрет `RELEASE_PUBLISH_TOKEN`

> Понадобится ~5 минут. Всё в браузере, под аккаунтом **vofka** (владелец обоих
> репозиториев). Ничего устанавливать не нужно.

---

## 📌 Что и зачем

- Приватный репозиторий **`vofka198119-code/fomoshield`** собирает все платформы
  (Android / Windows / Linux / macOS / iPhone) и выкладывает готовые бинарники
  `ScanCo.*` в **публичный** репозиторий **`vofka198119-code/fomoshield-releases`**.
- Приложение (auto-update) читает обновления **из публичного репозитория** —
  токен в приложение больше **не встраивается**, исходники приватного репозитория
  не раскрываются.
- Чтобы CI мог публиковать бинарники, нужны две вещи:
  1. **Публичный репозиторий** `vofka198119-code/fomoshield-releases`
     (уже создан, README добавлен).
  2. **Секрет `RELEASE_PUBLISH_TOKEN`** в приватном репозитории = ваш
     fine-grained PAT (создаёте сами — вы владелец публичного репозитория).

---

## 🎫 Шаг 0. Создать PAT (в своём аккаунте)

1. Открыть: **https://github.com/settings/tokens?type=beta** → **Generate new token**
2. **Token name:** `fomoshield-releases-publish`
3. **Expiration:** например 90 дней (позже нужно будет обновить)
4. **Repository access:** *Only select repositories* →
   **`vofka198119-code/fomoshield-releases`**
5. **Permissions → Repository permissions → Contents:** → **Read and write**
6. **Generate token** → скопировать значение (начинается с `github_pat_...`).
   GitHub показывает его **только один раз**.

---

## 🪜 Шаги (секрет)

### 1. Войти на GitHub под аккаунтом **vofka**
Открыть: **https://github.com/login**

### 2. Открыть страницу секретов приватного репозитория
Открыть сразу (ссылку можно вставить в адресную строку):

**https://github.com/vofka198119-code/fomoshield/settings/secrets/actions**

*(или вручную: репозиторий `fomoshield` → вкладка **Settings** → слева
**Secrets and variables** → **Actions**)*

### 3. Удалить старый секрет `RELEASE_READ_TOKEN` (больше не нужен)
1. В списке секретов найти **`RELEASE_READ_TOKEN`**.
2. Нажать на него → справа кнопка **Delete** (Удалить) → подтвердить.
3. *Почему:* раньше этот токен встраивался в приложение для чтения релизов из
   приватного репозитория. Теперь приложение читает из **публичного** репозитория —
   этот токен не используется и не должен нигде храниться.

### 4. Создать новый секрет `RELEASE_PUBLISH_TOKEN`
1. Нажать кнопку **New repository secret** (Новый секрет репозитория).
2. **Name:** `RELEASE_PUBLISH_TOKEN`
3. **Value:** вставить PAT из шага 0 (начинается с `github_pat_`).
4. Нажать **Add secret**.

### 5. Проверить
- В списке секретов появился **`RELEASE_PUBLISH_TOKEN`** ✅
- Готово. Больше ничего делать не нужно.

---

## ✅ Что произойдёт после

Следующий push в ветку `feature/auto-update` (или повторный запуск CI) соберёт
все платформы, выложит их в приватный GitHub Release, а джоба `publish-public`
зеркалирует бинарники `ScanCo.*` в публичный репозиторий
`vofka198119-code/fomoshield-releases`. Приложение найдёт обновление оттуда.

## ⚠️ Важно

- Секрет хранится в GitHub **зашифрованным**; значение видно только в момент
  создания.
- **Не выкладывайте токен** в чаты, issues, коммиты или файлы репозитория.
- Права на добавление секретов есть только у **админа** репозитория — у вас они
  есть (вы владелец).
